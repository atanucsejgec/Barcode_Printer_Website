TSC TE244 — 2-Up Label (38×38mm)

Gap-sensor mode: page size is 79 × 38 mm (label only). The 3mm gap between rows is handled by the printer's gap sensor, NOT by the HTML.

1) Chrome print dialog:
• Destination: TSC TE244
• Paper size: Barcode79x41 (the stock you created in the driver)
• Margins: None  •  Scale: Default (100) — NOT Fit to page
• Copies: 1 (copies are already built into the document)
• More settings → Background graphics: ON, Headers and footers: OFF

2) TSC driver (Devices & Printers → TSC TE244 → Printing Preferences):
• Stock tab (the one you're looking at):
    Name Barcode79x41, Type Die-Cut Labels,
    Width 79 mm, Height 38 mm  (← was 41, change to 38),
    Exposed Liner: Left 1.3 mm, Right 1.3 mm.
• Media Settings (or similar tab) → set Vertical Gap: 3 mm, Sensor Gap, Post-Print Action None.
• Options tab → Speed 2 ips, Darkness 8–10.

3) One-time calibration (do after loading a fresh roll):
Power OFF → hold FEED → power ON → release when it feeds 2–3 labels. Before every print job, tap FEED once so the roll is parked at a label start.

TSC TE244 — 2-Up Label (38×38mm)

Print dialog — set these EVERY time (or Chrome will scale/clip):
• Destination: TSC TE244
• Paper size: Custom 79 × 38 mm (or select the label size in the TSC driver)
• Margins: None
• Scale: 100 / Default — NOT “Fit to page”
• “More settings” → Background graphics: ON
• In the TSC driver → Stock → Gap sensor, Vertical gap = 3 mm
